# Waray-Waray (Samar) Translation Glossary

**Status: AI-drafted, pending local review.** These terms were drafted by Claude using general Waray-Waray
knowledge, not verified by a certified Samar-Waray speaker. Before treating any translation in this app as
"approved," a local reviewer (ideally a barangay official or resident from Samar, Western Samar specifically)
should read through this glossary and every `lang/war/*.php` file and correct anything that reads as
unnatural, too formal, or closer to Leyte usage than Samar usage.

This file is a **reference only** — it is not loaded by the application. Every `lang/war/*.php` file should
use these exact terms wherever the concept appears, so the same English word is never translated two
different ways in two different places.

## How to use this glossary
- Prefer natural, commonly-understood Samar Waray over literal or overly formal translations.
- If a term is already used in English by local residents in everyday speech (see "Retain in English"
  below), keep it in English rather than forcing an unnatural translation.
- When in doubt between two Waray options, prefer the shorter/more common one over the more "proper" or
  archaic one.

## Retain in English (do not translate)
Dashboard, Login, Password, OTP, GPS, SMS, Internet, Wi-Fi, PDF, Email, Clearance, Appointment, Profile,
Print, Status (in casual contexts "status" is also fine, though "kahimtang" is used in the glossary below
for form labels), Emergency.
